# wwwroot/lib

Este template carrega **Bootstrap 5**, **jQuery** e **jQuery Validation** via CDN
(veja `Views/Shared/_Layout.cshtml` e `Views/Shared/_ValidationScriptsPartial.cshtml`).

Se você preferir versionar as bibliotecas localmente em vez de usar CDN, esta é a
pasta esperada pela convenção do ASP.NET Core MVC. Use LibMan, npm ou download
manual e ajuste as referências no layout.

Qualquer das duas abordagens é aceita — se você mudar, registre o motivo no README.
